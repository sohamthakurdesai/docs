## Data cleaning stages for naive RAG

1. Get the chunks from the chunkDocument of the layout parser output json.
2. Clean the bleed through text that is wrongly being represented as Bengali or Gurumukhi text.
3. Remove markdown headings

# Metadata Schema

```yaml
chunk_id: string
pdf_file: string
pdf_page_number: int
printed_title: string|null
unit_type: string|null # editorial, speech, letter, article, chapter
printed_page_number: string
languages: enum
author: string
retrieval_relevant: boolean
editorial_theme: string
editorial_theme_en: string
theme_curator: string
theme_curator_source: enum
volume_name: string
original_source_name: string # Kesari, Maratha
original_source_type: string # Newspaper, Book, Letter
section_name: string
identified_date: string|null # date as extracted/inferred FOR THIS CHUNK specifically
```
